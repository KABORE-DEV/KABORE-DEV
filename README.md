## 👋 Bonjour, moi c'est Frank

Je suis **étudiant en 3ᵉ année de Génie Logiciel**, basé au Burkina Faso, et je construis progressivement mon parcours autour du **développement logiciel et web**.

J'aime comprendre ce que je construis plutôt que simplement faire fonctionner du code.

Mon approche est simple :

> **Comprendre → Construire → Tester → Améliorer**

Aujourd'hui, je travaille principalement autour de **React, Next.js, TypeScript, Laravel et NestJS**, avec un intérêt croissant pour l'architecture backend, les API, les bases de données et le déploiement.
