# 👨🏾‍💻 À propos

Je suis **Frank KABORE**, étudiant en **3ᵉ année de Génie Logiciel**,
basé au Burkina Faso.

Je m'intéresse principalement au **développement web**, à la conception
d'applications full-stack et à l'architecture logicielle.

Mon objectif est de progressivement maîtriser le cycle complet d'une
application :
